PIIK KENYA · PRE-LAUNCH

Image credits & source status

This pre-launch website makes the status of its sources explicit. No stock photograph has been copied from the design references.

PIIK identity

The original PIIK logo is retained in assets/logo.png. The smaller WebP version is trimmed and resized from that file, preserving the original blue artwork and wording.

Original editorial imagery

The six images used by this redesign were originally created for this project with OpenAI image generation on 17 November 2026. They are photorealistic AI-generated illustrations, not third-party stock photographs. No watermarked reference image was copied, extracted, retouched or used as an input image. The supplied screenshots guided the overall visual direction only.

These are fictional illustrative scenes. They do not show properties offered for sale, established PIIK members, verified professionals, clients, partnerships or completed transactions. The Nairobi-inspired skyline is a conceptual cityscape, not a documentary photograph or exact geographical view. Contextual accessibility descriptions and these credits explain their illustrative nature.

Image-by-image provenance

  • Residence: original Kenyan-inspired contemporary stone-and-glass home in a leafy garden. Architectural illustration, not a listing.
  • Apartments: original fictional apartment community inspired by contemporary Nairobi housing. No particular development or availability is represented.
  • Land: original Kenyan-inspired highland landscape. No parcel, boundary, ownership or development approval is implied.
  • Professional collaboration: original fictional East African professionals discussing a plan. These are not existing PIIK members or endorsements.
  • Diaspora: original fictional couple considering a possible home together. This is not a PIIK client story.
  • Cityscape: original Nairobi-inspired conceptual skyline with urban greenery at sunset. It is not a documentary record of the city.

The source manifest in assets/imagery/manifest.json records creation date, generation provenance, original file names, SHA-256 checksums and responsive sizes. Original PNG masters are preserved separately for the owner; the website serves only optimised local WebP derivatives.

Previous site images

The original repository assets remain preserved, but none of its photographs with undocumented provenance is used by this redesign. In particular, the former Nairobi preview image has been replaced. We make no new licence assertion about those unused source files.

Icons and typography

The interface icons and favicon use simple SVG geometry authored for this implementation. Georgia and Arial are locally available system fonts with fallbacks; no external font or icon files are downloaded.

Official resource status

Reviewed and recorded on 17 November 2026: nine linked destinations covering eight authorities were supplied by PIIK’s founder following independent research. The founder’s original research date was not specified. This environment could not retrieve those pages; their inclusion does not claim an automated or live status check.
