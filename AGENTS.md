# PIIK Kenya

PIIK is an independent Kenyan property information and verification resource. Its public promise is “Know before you commit.” Preserve the existing brand, navigation, checklists and useful URLs. Use the existing isolated checkout unless the founder requests a worktree.

Within granted permissions, implement, test, commit, open pull requests, merge passing changes and use the existing GitHub Pages deployment. Follow branch protections. Use standard-library Python, browser JavaScript and existing infrastructure where practical. Keep the additional operating cost at zero. Paid APIs, new subscriptions, credential creation, payments, sensitive data collection and changes to visibility, domain or DNS require separate authorisation.

Use first-party evidence and distinguish reporting, analysis and guidance. Source access or a register entry alone establishes no transaction assurance. Keep private or unreviewed material off the public repository and route allegations, significant legal interpretation, uncertain regulatory claims and privacy issues to authorised human review.

Run the test commands in [README.md](README.md), including browser checks when changing the public experience. Review generated diffs, require CI before merging, verify the exact Pages deployment and use a revert through the usual branch process for rollback. Escalate blocked access, sensitive editorial decisions, cost changes and deviations from the mission.

Start with [GOALS.md](GOALS.md), [ROADMAP.md](ROADMAP.md) and [the operating commands](docs/OPERATIONS.md).
